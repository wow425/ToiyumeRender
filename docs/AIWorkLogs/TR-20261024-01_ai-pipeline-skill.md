## 4. 设计概览

### 4.1 模块职责与依赖

```
SKILL.md            入口：五条硬规则 + 七阶段表 + 路由表

  ├─ references/01  架构红线（可机检，含"已绿/仍红/DEBT"三分）
```

## 5. 关键实现讲解

### 5.1 闸门的三种类型（`ai-check.ps1`）

```
empty    → 必须 0 命中（依赖倒置、D3D12 泄漏检查）
nonempty → 必须 >0 命中（反向判据：OnResize 必须有调用者）
debt     → 已知债务，只报告，永不让本次运行失败
```

**为什么需要 debt 类型**：施工中发现 **R10（Demos 不得持有 RT）与 G1（OnResize 必须有调用者）互斥** —— R2 修 resize 断链时，正是在 Demo 的 `OnResize` 里重绑 `Display::SceneColorBuffer`（`DeferredApp.cpp:107`）。在 WP6 收编路径之前，二者不可能同时为绿。
若把 R10 当硬闸门，skill 会让 AI 去"修"一个**故意为之的过渡状态**，制造回归。故降级为 DEBT，并要求「不在无关工作包里顺手修」。

### 5.2 脚本调 Python/PS 的坑（实测踩过）

| 尝试 | 失败原因 | 最终做法 |
|---|---|---|
| bash 内嵌 PowerShell 双引号 | 多层转义，`The string is missing the terminator` | 不调用 bash，全用原生 cmdlet |
| 中文注释 + UTF-8 无 BOM | PowerShell 5.1 按 ANSI 解码，中文被破坏导致字符串不闭合 | **脚本全 ASCII** |
| `Select-String -Recurse` | PS 5.1 无此参数 | `Get-ChildItem -Recurse` 枚举后 `Select-String -Path` |
| `Status = (if (...) {...})` | PS 不支持 if 作表达式 | `$(if (...) {...})` |

### 5.3 边界条件

- 脚本按 `$PSScriptRoot` 上溯找 `CMakeLists.txt` 定位仓库根，容忍被拷到别处。
- 目录不存在时 `Get-Hits` 返回空数组而非报错（`Features/` `Paths/` 尚不存在）。
- md5 扫描跨 `R*_evidence` 目录统一分组（初版按目录分组，漏掉 `final_r1` == `resize_f` 这类跨目录碰撞——**是自测发现的**）。
