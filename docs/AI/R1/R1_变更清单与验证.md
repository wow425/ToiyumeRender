## B. 验证命令

### B.1 构建

```bat
set VCPKG_ROOT=C:\dev\vcpkg
scripts\build.bat Debug clean
scripts\build.bat Release clean
```

### B.2 验证 Shader 依赖（关键）

```bash
# 改任意 HLSL 后重建，日志中应同时出现：
#   Compiling Shader: ...
#   Building CXX object .../DeferredRenderer.cpp.obj
touch Engine/Shader/02_Deferred/LightingPS.hlsl
scripts\build.bat Debug
```

若只出现前者，说明依赖链断了。

### B.3 回读截帧

```bat
out\build\Debug\Demos\DeferredApp\DeferredApp.exe -Screenshot D:\shots
rem 会在第 30 / 90 帧导出 screenshot_30.png / screenshot_90.png
```

### B.4 重新烘焙模型（槽位顺序变更后必须）

```bat
scripts\run.bat Debug Deferred -RebuildModels
```

### B.5 验证输入链路

启动后按 WASD，相机应移动。若无效，检查：
1. 启动日志是否有 `[Boot] GameInput: DirectInput 不可用，键鼠输入已禁用`
2. 有该行是正常的（会走 Win32 消息通路），WASD 仍应工作

## C. 本次排查使用的调试手段（可复用）

### C.1 GPU 回读截帧

```cpp
// 必须在外层 Context Finish() 之后调用
Renderer::DebugCapture::SaveColorBufferToPNG(*sceneColorBuffer, L"D:\\shot.png");
```

支持 `R8G8B8A8_UNORM` 与 `R16G16B16A16_FLOAT`。

### C.2 Debug View 通道

`LightingPS.hlsl` 末尾保留了一个调试开关（可临时改 `dbg` 值）：

```hlsl
int dbg = 0;   // 0=正常 1=BaseColor 2=Normal 3=Metallic 4=Roughness 5=AO 6=Emission 7=Depth
```

修改后**必须**确认 `DeferredRenderer.cpp` 也重编了（见 B.2）。
