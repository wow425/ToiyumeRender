## B. 复现命令

### B.1 首次构建

```bat
rem 前置：设置 vcpkg 根目录（只需一次，或写进系统环境变量）
set VCPKG_ROOT=C:\dev\vcpkg

rem 构建 Debug
scripts\build.bat Debug clean

rem 构建 Release
scripts\build.bat Release clean
```

### B.2 运行

```bat
scripts\run.bat Debug Forward
scripts\run.bat Debug Deferred
scripts\run.bat Debug RayTracing

rem 强制重新烘焙模型缓存
scripts\run.bat Debug Deferred -RebuildModels
```

### B.3 指定资产目录（CI / 多机）

```bat
set TOOIYUME_ASSETS_ROOT=D:\shared\TooiyumeAssets
scripts\run.bat Debug Deferred

rem 或用命令行参数
DeferredApp.exe -AssetsRoot D:\shared\TooiyumeAssets
```

### B.4 验证 Shader 依赖追踪

```bash
touch Engine/Shader/02_Deferred/DeferredCommon.hlsli
scripts\build.bat Debug
# 预期只重编 StaticMeshVS / GBufferPS / LightingPS
```

### B.5 启用详细追踪日志

```bat
cmake -S . -B out/build/Debug -G Ninja ^
      -DCMAKE_BUILD_TYPE=Debug ^
      -DCMAKE_TOOLCHAIN_FILE=%VCPKG_ROOT%/scripts/buildsystems/vcpkg.cmake ^
      -DCMAKE_C_COMPILER=cl.exe -DCMAKE_CXX_COMPILER=cl.exe ^
      -DCMAKE_CXX_FLAGS="/DTOOIYUME_VERBOSE_LOG"
```

## C. 常见错误对照表

| 现象 | 原因 | 解决 |
|---|---|---|
| `未找到 vcpkg 工具链` | 没设 `VCPKG_ROOT` | `set VCPKG_ROOT=<vcpkg根目录>` |
| `requires a manifest with a specified baseline` | `vcpkg.json` 缺 baseline | 已修；若复现请确认文件含 `builtin-baseline` |
| `cmake was unable to find Ninja` | 不在 VS 开发者环境 | 用 `scripts/build.bat`（自动探测），或先 `vcvars64.bat` |
| 构建卡在 `PowerShell-7.5.3` 下载 | vcpkg 选到了 VS 内置实例 | `scripts/build.bat` 已处理；手写命令时确认 `VCPKG_ROOT` 在 `vcvars` 后仍指向自己的 vcpkg |
| `LOG_TRACE 找不到标识符` | 旧 `.obj` 未重编 | `scripts/build.bat Debug clean` |
| 新增 `.cpp` 不参与编译 | `GLOB` 无 `CONFIGURE_DEPENDS` | 重新 configure（`clean` 即可） |
| 画面全黑 | R1/R4 范畴（渲染正确性） | 见总报告 §2.2 |
| 启动即 `__debugbreak` | Debug Layer 断点 | 已改为只 break ERROR/CORRUPTION |
