## §3 关键技术的逐项详解

### A2-01 / A2-02 BRDF 基元与组合〔必需〕

**功能**：微表面理论的标准实现。

**结构（逐函数实测）**：

| 函数 | 行号 | 用途 |
|---|---|---|
| `D_GGX` | `brdf.hlsli:8` | 各向同性法线分布，`d = k*k*(1.0/PI)` `:15` |
| `D_GGX_Anisotropic` | `:19` | 各向异性法线分布，`(1.0/PI)` `:30` |
| `D_Charlie` | `:33` | 布料专用 NDF，`2.0*PI` 归一 `:39` |
| `V_SmithGGXCorrelated` | `:42` | 高度相关几何遮蔽 |
| `V_SmithGGXCorrelated_Anisotropic` | `:56` | 各向异性版 |
| `V_Kelemen` | `:67` | 布料几何项 |
| `V_Neubelt` | `:73` | 另一布料变体（The Order 1886） |
| `iorToF0` / `f0ToIor` | `:79` / `:84` | 折射率 ↔ F0 互转 |
| `BRDF_GetSpecular` | `:156` | 组合 F·D·V |
| `BRDF_GetDiffuse` | `:189` | `baseColor/PI`（Lambert） |

**π 归一化的落点（施工关键，2026-10-24 22:5x 实测更正）**：`PI` 定义在 `shaders/globals.hlsli:793`（`#define PI 3.14159265358979323846`）。

| 位置 | 事实 |
|---|---|
| `brdf.hlsli:15` / `:30` / `:39` | GGX 与 Charlie 的**法线分布函数内部**自带 `1/PI`（NDF 的归一化），与「漫反射能量」无关 |
| `brdf.hlsli:189 BRDF_GetDiffuse` | **不含 `/PI`**——`return diffuse * surface_to_light.NdotL;`（`:203`），只做菲涅尔/subsurface/sheen/clearcoat 修正 |
| `lightingHF.hlsli:49 ApplyLighting` | **真正的 `/PI` 在这里**：`half3 diffuse = lighting.direct.diffuse / PI + ...` |

**结论（与本节旧版相反）**：漫反射的 π 归一化落在**光照累加处（`ApplyLighting`）**，不在 BRDF 函数内。旧版本曾把答案写成「在 BRDF 函数内」，属**未回源推断**，已按实测更正。施工含义：抄 `BRDF_GetDiffuse` 时不要自己再除 π，否则漫反射暗 3.14 倍；反之若把 `ApplyLighting` 的 `/PI` 去掉而没有在别处补回，则亮 3.14 倍。

**对本项目取舍**：**必需**。TooiyumeRender 的 `Engine/Shader/05_BRDF/BRDF.hlsl` 已实现同族函数且经 RB6 逐项核对「数学正确」，缺的是**归一化的单一来源**；建议直接以本卷的函数清单为对照表做一次一致性核查。

### A2-04 EnvBRDFApprox〔必需，且解释了一个已知缺陷）

**功能**：在没有 BRDF LUT 的情况下，用解析式近似 `∫ F·G·D` 的积分结果。

**结构**：`F_Schlick`(`surfaceHF.hlsli:13`) 给出菲涅尔；`EnvBRDFApprox`(`:21`) 用 Karis 2013 的 A/B 拟合多项式，`:28` 返回 `SpecularColor*AB.x + AB.y`。

**对本项目取舍**：**必需**。项目已有 BRDF LUT（`BRDFLUTCS.cso` 在 ShaderCache 中），比 WE 更正确；但**必须注意**：两条路径（LUT 采样 vs 解析近似）不能在同一材质上混用，否则高光亮度不一致。

### A2-08 阴影〔必需〕

**功能**：方向光级联阴影 + PCF/PCSS 软阴影。

**结构**：`shadowHF.hlsli` 466 行内提供级联选择、深度比较、PCF 核、PCSS 的 blocker 搜索；绘制侧在 A1-04 的 `DrawShadowmaps`。

**对本项目取舍**：**必需**（但可减配）。最小实现：1 级方向光 + 3×3 PCF，不需要级联与 PCSS。

### A2-12 IBL 预过滤〔必需〕

**功能**：把环境立方体贴图按粗糙度过滤，供镜面 IBL 采样。

**结构**：`filterEnvMapCS.hlsl` 用 GGX 重要性采样（`ImportanceSampleGGX` `:20`），按 `computeLod`(`:51`) 决定每个 mip 的粗糙度，`main`(`:81`) 逐 mip dispatch。这与本项目 `EquirectangularToCubemapCS` + `irradianceConvolutionCS` + `BRDFLUTCS` 三件套中的「specular prefilter」对应。

**对本项目取舍**：**必需**。项目已有预计算链（ShaderCache 实证：`BRDFLUTCS.cso`、`EquirectangularToCubemapCS.cso`），缺的是 prefilter 的 mip↔roughness 映射正确性验证（见 09 §8.1 的 U-1）。

### A2-11 大气 LUT 链〔规模不匹配〕

**功能**：物理正确的大气散射（Bruneton 模型），5 张 LUT 依次依赖。

**结构**：透射 LUT → 多次散射 LUT → 天空亮度 LUT → 天空视图 LUT → 相机体积 LUT，各自一个 CS，C++ 端 `ComputeSkyAtmosphereTextures`(`wiRenderer.cpp:8819`)、`...SkyViewLut`(`:8943`)、`...CameraVolumeLut`(`:8991`)。

**对本项目取舍**：**规模不匹配**。5 张 LUT + 每次大气参数变化全量重算，对本项目（单场景、固定天气、学习目标）收益极低。A2-09 的静态天空 + 一张烘焙 cubemap 已足够。

## §4 光照数据流总图

```
Material (StructuredBuffer, bindless)
   │  surfaceHF.load() :1088
   ▼
Surface { baseColor, f0, normal, roughness, metalness, ... }   (surfaceHF.hlsli:75 起)
   │
   ├──直接光──→ for each light:
   │              shadowHF 采样 (A2-08)
   │              BRDF_GetSpecular :156 / BRDF_GetDiffuse :189
   │              ↓
   │            Lighting.rgb 累加  (lightingHF.hlsli:22)
   │
   └──环境光──→ 漫反射: SH / irradiance
                 镜面: prefiltered cubemap (mip=roughness) × EnvBRDFApprox :21
   ▼
shadingHF 组装 → 输出（GBuffer / Forward RT）
```
