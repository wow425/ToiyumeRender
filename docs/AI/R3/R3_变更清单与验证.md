## B. 验证命令

### B.1 构建（唯一入口）

```bat
set VCPKG_ROOT=F:/VS/rep/vcpkg
scripts\build.bat Debug clean
scripts\build.bat Release clean
```

预期：两者 exit 0。Release 唯一警告 `BaseRenderer.cpp(77): warning C4319`（既有）。

### B.2 注册表非空（回归守卫）

```bat
scripts\run.bat Debug RendererDemo -R3Test D:\tmp\r3
```

日志前几行必须出现：

```
[R3] 已注册 Renderer 数量：2
[R3]   - DeferredRenderer
[R3]   - ForwardRenderer
```

若为 0，说明 `RendererRegistry.cpp` 的显式注册被破坏（见 R3 文档 §3.1）。

### B.3 脚本化验收（11 步）

```bat
scripts\run.bat Debug RendererDemo -R3Test D:\CS-Self-Study\Computer_Graphics\DX12\TooiyumeRender\docs\AI\R3
```

日志应依次出现 `[R3-Test] [0]` … `[10]` 与 `[R3-Test] all steps done`，退出码 0，目录下产出 10 张 1920×1080 PNG。

### B.4 Debug Layer 干净

```bash
grep -c "D3D12 ERROR\|D3D12 WARNING\|CORRUPTION\|LIVE OBJECT" out/build/Debug/Demos/RendererDemoApp/tooiyume_log.txt
```

预期只命中第 5 行的 InfoQueue 配置行（`[Boot] Graphics: InfoQueue break on ERROR/CORRUPTION only`）。

### B.5 Debug / Release 一致性

```bash
cd docs/AI/R3 && md5sum *.png
cd out/r3_rel  && md5sum *.png
```

`r3_03` / `r3_04` / `r3_06` / `r3_07` / `r3_08` 的 md5 应完全一致；其余有极小字节差（浮点/编译差异）。

### B.6 架构红线自检

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "docs/AI/渲染器AI编程流程skill/scripts/ai-check.ps1"
```

R3 收尾实测（基线 HEAD `51c09d0` + 78 项未提交改动）：`RESULT: 6 gate(s) RED` —— R1 / R2 / R3 / R4 / R13 / R9 全为既有分层债（WP0–WP8 计划内），**`G1 OnResize must have a caller` 为 PASS**。R3 相比 R3 前新增：R9 +1（`RendererDemoApp.cpp:752` 的 `DrawPass::kOpaque`）、R1 +2（`LightingSystem::ApplyParams` 两处资源状态转换）。详见 `docs/AIWorkLogs/TR-20261026-01_R3-统一入口与交互工作台.md` §9 E8。
